# ADR 0009: UI/UX DESIGN ARCHETYPES AND THEME PRESET CATALOG

* **Status**: Approved (Accepted)
* **Decision date**: 2026-11-04
* **Decided by**: UI/UX Specialist & Principal Architect

---

## 1. CONTEXT

In traditional project starter kits (Starter Kits), the interface is often bound to one fixed style (usually default Tailwind or gray/blue Bootstrap). When users or AI Coding Agents want to deliver a product in a different segment (for example a nostalgic Retro Windows XP app, a Cyberpunk HUD interface for a security system, or a rule-breaking Neubrutalism style for a Creator product), they spend a lot of time reconfiguring the whole system of colors, corner radii, shadows and fonts.

Moreover, large language models (LLMs) tend to generate "generic" interfaces without a strong visual identity unless they are given a clear set of design constraints (Visual DNA Constraints).

---

## 2. DECISION

We decided to integrate the **UI/UX Design Archetypes & AI Visual DNA Prompt Kit** system into `Project-Builder-4-Agents`:

1. **Standardize 7 Aesthetic Universes & 14+ Style Presets**:
   - Fully documented in `profiles/design/design-archetypes-catalog.md`.
   - Directly connected to reputable open-source projects (`98.css`, `XP.css`, `NES.css`, `RPGUI`, `Arwes`, `PaperCSS`, `Terminal.css`, `Magic UI`, `neobrutalism-components`).

2. **Provide the AI Visual DNA Prompt Cookbook**:
   - Located at `profiles/design/visual-dna-prompts.md`.
   - Provides standardized System Prompt snippets for each visual style (Linear Pro Max, iOS Glassmorphism, Neubrutalism, Cyberpunk HUD, Windows XP, Hacker Terminal, Hand-Drawn Paper) so users can activate a style instantly when working with an AI Agent (Cursor, Claude Code, Antigravity, v0).

3. **Separate Component Logic from Visual DNA**:
   - Keep the logic structure of Headless Components unchanged (state, accessibility, form handling).
   - Style variants (Aesthetics) are driven by Token sets (Tailwind classes, CSS variables, shadow profiles).

4. **Equip the Frontend with an Interactive Theme Showcase**:
   - Build the module `profiles/frontend/starter/src/features/theme-showcase/` so users can click to switch directly between styles and experience them before choosing a style for the project.

---

## 3. CONSEQUENCES

* **Pros**:
  - Maximum project start-up speed: pick one preset and the whole visual identity is set consistently.
  - Precise guidance for the AI Agent: reduces by 90% the errors of skewed or "boring" interfaces generated by AI.
  - Platform independent: any team using React, Vue, Svelte or plain HTML can consult the Design Tokens table and apply it.
* **Cons**:
  - Documentation must be maintained and new design trends added periodically.
* **System Impact**:
  - Adds no heavy dependency in `profiles/frontend/starter/`.
  - Keeps the Anti-Crash standard and the modularity of Bulletproof React.
