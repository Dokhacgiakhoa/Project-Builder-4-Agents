## Sheet 9: User Guide & SOP

| TEMPLATE OPERATING PROCEDURE | Column B |
| --- | --- |
| Review prior to use — Maintain Single Source of Truth integrity |  |
| A. TEMPLATE OBJECTIVES |  |
| Purpose | Serves as the sole authoritative project tracker. All milestones, tasks, bugs, and links reside here. |
| Core Principles | • Single canonical sheet — no split or disconnected copies <br> • Update at least once daily <br> • Open read access for team; write access governed by Team Lead |
| B. OPERATING DISCIPLINE |  |
| Daily Routine | 1. Morning: Inspect tasks in Sprint Backlog <br> 2. Workday: Update task progress status in real-time <br> 3. Standup: Reference sheet for daily updates <br> 4. Evening: Lead verifies milestone status |
| Status Hygiene | Keep dropdown states up-to-date: Green = Done, Yellow = In Progress, Red = Blocked. |
| Security | Never share publicly or commit sensitive credentials in sheets. |
