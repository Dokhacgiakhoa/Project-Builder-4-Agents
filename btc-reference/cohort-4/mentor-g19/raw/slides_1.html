Architecture Design — Thiết kế theo đặc tính sản phẩm

chat · search · realtime inference

Testing — Mock everything

Code viết ra phải mock được toàn bộ module — mock được thì mới test được
mock DB mock LLM mock agent tools mock external API
Liệt kê sẵn kịch bản test — không sót case
✅ happy path ⚠️ edge case ❌ error / failure case 🔀 concurrent / load 🛡️ security / abuse
🧩 Unit Test mock mọi dependency · chạy nhanh · nhiều nhất auto · CI
🔗 Integration Test ghép module thật — DB · queue · service auto · CI/CD
🧑‍💻 Manual E2E test lại toàn hệ thống trước prod human
🛑 Automation nhiều đến đâu — chốt chặn cuối trước production vẫn là con người
