# evals/ — published evidence only

This folder holds **results** (reports and raw measurement data) that back claims made in `README.md`, `scripts/README.md` and the ADRs.

* `results/*.md` — evaluation reports. `results/raw/` — raw outputs. `results/screens/` — screenshots embedded in reports.
* `c1-bootstrap-protocol.md` — specification of the planned end-to-end Agent bootstrap eval.

The scripts and handoff briefs that produced these results are **not published**: they live in the maintainer's private lab. Reports therefore mention script and brief names as provenance only; those files are not in this repo. A claim is verified by its raw data here, not by re-running the private scripts.
