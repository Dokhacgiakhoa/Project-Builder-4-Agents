def audit_job_status(job_id, since=0):
    job = _AUDIT_JOBS.get(job_id)
    if job is None:
        return {"success": False, "error": "Không tìm thấy phiên quét."}
    auditor = job["auditor"]
    logs = list(auditor.scan_logs) if auditor is not None else []
    status = {"success": True, "job_id": job_id, "state": job["state"], "pct": job["pct"], "message": job["message"],
              "target_dir": job.get("target_dir", ""),
              "elapsed": round(time.time() - job["started"], 1),

              "plan": list(auditor.scan_plan) if auditor is not None else [],
              "current": auditor.scan_current if auditor is not None else None}
    if job["state"] == "done":
        status["result"] = job["result"]
    return status

## 8. Mục thất bại (What Failed) & Chưa kiểm chứng (Not Verified)

- **Mục thất bại (What Failed)**:
  1. **Tiến trình engine bị mồ côi (Orphan engine) khi shell bị cưỡng chế tắt**: Trong kịch bản shell bị kill bằng `Stop-Process -Force` (hoặc shell bị crash), `reviewer-engine.exe` vẫn tiếp tục chạy ngầm vô thời hạn do cờ `--watchdog` mặc định là 0 (tắt). Cần một cơ chế dọn dẹp hoặc watchdog mặc định bật với thời gian chờ dài để thu hồi tiến trình.
  2. **Các kiểm tra phụ thuộc desktop tương tác trong môi trường headless/sandbox**: `CopyFromScreen` (lỗi "The handle is invalid"), `MainWindowTitle` (trả về rỗng `[]`), và `$p.CloseMainWindow()` (không đóng được form dẫn đến việc shell phải bị force-kill sau 10s timeout) bị thất bại do phiên làm việc của Agent chạy trong desktop cô lập không có display DC.

- **Mục chưa kiểm chứng (Cần người dùng kiểm thử thủ công trên desktop tương tác vật lý)**:
  1. Chụp ảnh màn hình bằng `CopyFromScreen` trên phiên người dùng có gắn card đồ họa và màn hình hiển thị trực tiếp.
  2. Kiểm tra việc hiển thị tiêu đề cửa sổ trên thanh taskbar/desktop chuẩn qua lệnh PowerShell `$p.MainWindowTitle`.
  3. Lệnh `$p.CloseMainWindow()` khi chạy trực tiếp từ session desktop có người dùng đăng nhập tương tác.
