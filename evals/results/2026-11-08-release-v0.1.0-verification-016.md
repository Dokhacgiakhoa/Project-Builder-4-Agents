## Method: gates vs measurements
A gate needs a logical basis, not a chosen number.
* **G1 correctness:** all automated tests pass.
* **G2 identity:** the exe, which claims to be this source, behaves identically to `python scripts/engine_main.py` on the same input.
* **G3 claim match:** numbers published in README equal the measurement, otherwise the README is wrong.

Everything else is a measurement and has no PASS/FAIL.
