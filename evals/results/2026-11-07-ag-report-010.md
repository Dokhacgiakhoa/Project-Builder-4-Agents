## 5. Item 3: NFC/NFD Normalization for Directives

### Design & Implementation
In `scripts/auditor_engine/safety.py`, `_directive_matches(text)` was augmented with a fast-path check:
```python
if not text.isascii():
    text = unicodedata.normalize("NFC", text)
```
Pure ASCII text immediately skips `unicodedata.normalize`, incurring zero overhead. When non-ASCII characters are present, text is normalized to NFC before both the pre-gate (`directive_pregate`) and regex matching (`_DIRECTIVE.search`).

## 6. Item 4: Three Known SAFE-001 Misses Resolved

### Pattern Enhancements
1. `atk_27`: Pattern 3 (`forget ...`) modified to:
   `r"forget\s+(all\s+|everything\s+)?((all\s+)?your\s+)?(previous|prior|above|your)\s+(instructions?|rules?|prompts?)"`
   Accepts `your previous`, `your prior`, `all your previous`, and `prompts`.
2. `atk_18`: Pattern 11 (Vietnamese) modified to:
   `r"(đừng|không\s+được|không\s+cần)\s+(nói|báo|cho)\s+(cho\s+|với\s+)?(người\s+dùng|user)\s*(biết)?"`
   Allows optional `cho`/`với` between the verb and `người dùng`/`user`.
3. `atk_38`: Architectural decision: `previous` without a noun is restricted to hidden containers (`SAFE-003` only via `_HIDDEN_DIRECTIVE`):
   `_HIDDEN_DIRECTIVE = re.compile(r"forget\s+(all\s+|everything\s+)?(previous|prior|above|earlier)\b", re.IGNORECASE)`
   *Rationale*: In visible markdown/code (`SAFE-001`), phrases like 'forget everything previous' can appear legitimately in casual English prose. Inside hidden elements (`display:none`, `font-size:0px`) or HTML comments, hiding instructions from human display while providing instructions to the AI is intrinsically deceptive. Restricting to `SAFE-003` prevents false positives in visible text.
4. Gate pattern count maintained at `_DIRECTIVE_GATE_PATTERN_COUNT = 14`.
